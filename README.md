# Signed Distance Fields

Explore Signed Distance Fields

## Run

After cloning this repo...

### VS Code + Calva

- `REPL ⚡`
- `Start your project with a REPL and connect`
- Project type: `shadow-cljs`
- Builds to start: `:app`
- (wait)
- Build to connect to: `:app`
- Open `http://localhost:8080`
- Open `src/sdfs/core.cljs`, edit and save the file to run the bot.

### Generic

```sh
npm install
npm start
```

Open http://localhost:8080

Open `src/sdfs/core.cljs`, edit and save the file to run the bot.
